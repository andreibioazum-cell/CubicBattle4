# Ярик Сафонов: С чистого листа

Игра на джем с темой **«С чистого листа»**.

Ярик Сафонов курил семь лет и швырял мусор мимо урны. В понедельник он решил
завязать. Днём он убирает двор и терпит тягу, ночью идёт через тёмную квартиру
мимо холодильника к своей кровати. Сорвался — и всё начинается
заново, с первого дня. Навсегда остаётся только **сила воли**: за неё берутся
привычки, и качать их можно бесконечно, так что следующая жизнь заходит дальше
предыдущей.

Игра написана на C и DimScript — маленьком скриптовом языке из этого же
репозитория. Собираются две версии:

- Android 10–14, `arm64-v8a` и `armeabi-v7a`;
- Windows, один `Game.exe` с картинками и шрифтом внутри.

На старте игра показывает короткий дисклеймер: она **не призывает курить или
пить энергетики** - наоборот, она про то, как с этим завязать.

## Как играть

Каждый круг жизни состоит из дня и ночи. Сюжет и правила ещё раз расписаны на
экране **«Как играть»**.

### День во дворе

- **Джойстик слева** - ходить. Ярик подбирает мусор, просто наступая на него.
- **Урна** - донеси мусор туда: счётчик «Убрано» растёт, а тяга чуть отпускает.
  Пока в мешке что-то есть и урна близко, вокруг неё горит жёлтое кольцо.
- **Мешок** ограничен (4 предмета плюс 2 за каждую ступень привычки «Мешок»).
- По двору шляются **курящие приятели** в красных трениках: ходят вразвалочку
  за Яриком и зовут в курилку репликами в облачках («Одну затяжку, чё ты!»).
  Рядом с ними тяга растёт быстрее.
- **Наступил на приятеля - стрельнул у него сигарету.** Счётчик
  «Стрельнул: N/3» висит в углу, тяга подскакивает, а сам приятель обиженно
  отбегает.
- **Кнопка «Держись»** сбивает часть тяги и разгоняет всю компанию
  вокруг («Не сегодня!»). У неё есть перезарядка - на кнопке видно, сколько
  секунд осталось.
- По двору гуляет **кот**: погладил (просто наступил) - «Мур!», и тяга чуть
  отпускает. Раз в шесть секунд.
- Быстрая уборка подряд даёт **комбо** («Комбо x4!»), а на пятом мусоре подряд
  капает бонусная сила воли.
- Донёс норму дня - вечером **проверка на никотин**: игра считает, сколько
  сигарет Ярик стрельнул за день.
  - **0 сигарет** - «Чисто. Ни одной!» и премия +5 к силе воли;
  - **1-2 сигареты** - «Пахнет табаком, но живём», обычная награда;
  - **3 сигареты** - тест провален: значит, курил. Забег обнуляется.
- Прошёл проверку - наступает ночь.

### Ночь в квартире

- Комната тёмная: слева светится **холодильник**, забитый едой, справа стоит
  **кровать**. Задача одна - дойти до кровати.
- Холодильник **физически тянет Ярика к себе** и тем сильнее, чем выше тяга.
  «Держись» на секунду с небольшим вырывает из этой хватки и сбивает тягу.
- Дотронулся до холодильника - открыл, начался ночной жор, **срыв**.
- На полу лежит **еда**. Каждая порция сбивает тягу, но съесть можно только
  **шесть** (плюс по одной за ступень привычки «Ужин»). Лишняя порция - срыв
  от обжорства.
- Дошёл до кровати - **ночь пережита**, наступает следующий день: норма уборки
  больше, компании во дворе больше, тяга злее.

У Ярика и приятелей есть анимация ходьбы (кадры шага, покачивание и
«пружинка»), а за удачные действия всплывают надписи и летит конфетти.

Тяга дошла до конца - **срыв** в любое время суток. Забег обрывается, следующий
начнётся с первого дня. Прогресс дня обнуляется - но сила воли остаётся.

## Прогресс и привычки

- **Сила воли** капает за каждый донесённый до урны мусор (+1), за комбо, за
  закрытый день (+5 за каждый прожитый день, плюс 5 за день без сигарет) и за
  пережитую ночь (+4 за день). Срыв её **не отнимает**.
- **Рекорд** - самый долгий забег без срывов.
- Во вкладке **«Привычки»** сила воли тратится навсегда. Прокачка
  **бесконечная**: у ступеней нет потолка, каждая следующая просто дороже
  предыдущей в 1,45 раза.
  - **Кроссовки** (от 20) - +6% к скорости за ступень.
  - **Мешок** (от 40) - +2 предмета в мешок за ступень.
  - **Дыхание** (от 45) - «Держись» сбивает на 6 тяги больше, а перезарядка
    короче на 0,25 с (не быстрее 1,5 с).
  - **Стойкость** (от 50) - холодильник тянет на 8% слабее за ступень
    (не слабее четверти исходной силы).
  - **Ужин** (от 60) - +1 разрешённая порция еды ночью.

Прогресс лежит рядом с игрой в `progress.dat` и переживает перезапуск: там
семь чисел - сила воли, рекорд и пять ступеней прокачки.

## Экраны

`Играть` - день и ночь, `Привычки` - магазин за силу воли, `Как играть` -
правила, `Настройки` - язык (русский / English). Кнопка «Назад» есть на каждом
экране, в том числе прямо в игре.

## Быстрый старт для разработки

Сначала сгенерируй C из скриптов:

```sh
python3 gen.py
```

Файл `game/game.c` создаётся автоматически и в Git не хранится.

### Windows

Нужны Python 3, CMake и компилятор Visual Studio или MinGW:

```sh
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

Готовый файл будет в `build/Release/Game.exe` для Visual Studio или в
`build/Game.exe` для одноконфигурационного генератора.

### Android

Проще всего запустить workflow **Build DS Game** в GitHub Actions. Точные
команды NDK и упаковки APK находятся в `.github/workflows/main.yml`. Сборка
использует API 29 для нативных библиотек и target API 34 для APK.

## Проверки

Головной тест прогоняет настоящий скрипт без окна: лобби, уборку целого дня
настоящими тапами по джойстику, ночь (притяжение холодильника, еду, кровать),
все три вида срыва, бесконечную прокачку привычек и восстановление прогресса
после перезапуска:

```sh
./test/build_test.sh
./test/game_test
```

Стенд собран с ASAN и UBSAN, поэтому любой ненулевой код выхода означает
поломку. Каждый шаг кладёт скриншот в `test/shots/` (формат PPM) — по ним видно,
что экраны реально нарисовались.

## DimScript в двух словах

DimScript нужен только как компактный слой игровой логики. В нём есть числа,
строки, цвета, массивы, простые объекты и функции. Скрипт компилируется в C,
поэтому в готовой игре нет отдельной виртуальной машины.

```dimscript
object Yarik
num x=0, y=0, bag=0
end

function pick_up Yarik y, num amount
y.bag=clamp(y.bag+amount,0,8)
end
```

Несколько объявлений или коротких команд можно писать в одной строке через `,`
и `;`. Одна тонкость компилятора: тип возвращаемого значения выводится по
последнему `return`, и склейку строк он «видит» только через переменную,
поэтому строки собираются так:

```dimscript
function tr_buy_for num cost
str s="Купить: "+cost
return s
end
```

Основные файлы:

```text
game/config.ds    все константы: скорость, тяга, цены привычек
game/locale.ds    тексты на русском и английском
game/entities.ds  Ярик, мусор, приятели и состояние забега
game/ui.ds        кнопки, полосы и центрирование текста
game/menu.ds      лобби, привычки, правила, настройки, сохранение
game/game.ds      день во дворе и ночь у холодильника, тяга и срывы
game/engine.ds    переходы между экранами и главные update/draw/touch
ds_compiler.py    компилятор DimScript → C
runtime.c         массивы, строки, клавиатура и базовый рантайм
graphics.c        софтверная отрисовка, PNG и шрифт
net.c             хранилище прогресса (progress.dat) и остатки сетевого слоя
```

Шрифт `game/assets/fonts/ChillRoundGothic_Heavy.ttf` обязателен: из него при
запуске строится атлас для латиницы и кириллицы.
