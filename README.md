# Ярик Сафонов: С чистого листа

Игра на джем с темой **«С чистого листа»**.

Ярик Сафонов раньше пил и швырял мусор мимо урны. Однажды он решил завязать —
и теперь каждый день выходит во двор, убирает за собой и за другими и борется с
тягой. Тяга дошла до конца — срыв, и всё начинается заново, с первого дня.
Навсегда остаётся только **сила воли**: за неё берутся привычки, с которыми
следующая жизнь заходит дальше предыдущей.

Игра написана на C и DimScript — маленьком скриптовом языке из этого же
репозитория. Собираются две версии:

- Android 10–14, `arm64-v8a` и `armeabi-v7a`;
- Windows, один `Game.exe` с картинками и шрифтом внутри.

## Как играть

- **Джойстик слева** — ходить. Ярик подбирает мусор, просто наступая на него.
- **Урна** — донеси мусор туда: счётчик «Убрано» растёт, а тяга чуть отпускает.
  Пока в мешке что-то есть и урна близко, вокруг неё горит жёлтое кольцо.
- **Мешок** ограничен: 4 предмета (8 с привычкой «Большой мешок»). Набрал —
  иди к урне.
- **Красная полоса «Тяга»** растёт сама и тем быстрее, чем дальше зашёл забег.
  Бутылки во дворе ползут к Ярику: рядом с ними тяга разгоняется, а касание —
  сразу большой скачок.
- **Кнопка «Держись»** сбивает часть тяги и расшвыривает бутылки вокруг.
  У неё есть перезарядка — на кнопке видно, сколько секунд осталось.
- Донёс до урны всю норму дня — **день прожит трезво**, дальше следующий день:
  норма больше, бутылок больше, тяга злее.
- Тяга дошла до конца — **срыв**. Забег обрывается, и следующий начнётся
  с первого дня. Прогресс дня обнуляется — но сила воли остаётся.

## Прогресс и привычки

- **Сила воли** капает за каждый донесённый до урны мусор (+1) и за закрытый
  день (+5 за каждый прожитый день: день 3 даёт 15). Срыв её **не отнимает**.
- **Рекорд** — самый долгий трезвый забег.
- Во вкладке **«Привычки»** сила воли тратится навсегда:
  - **Кроссовки** — 5 ступеней, каждая +9% к скорости. Первая стоит 20, каждая
    следующая на 10 дороже.
  - **Большой мешок** (60) — мешок на 8 предметов вместо 4: меньше беготни.
  - **Дыхание** (80) — «Держись» сбивает 46 тяги вместо 30, а перезарядка
    падает с 6 до 3,5 секунды.

Прогресс лежит рядом с игрой в `progress.dat` и переживает перезапуск.

## Экраны

`Играть` — двор, `Привычки` — магазин за силу воли, `Как играть` — правила,
`Настройки` — язык (русский / English). Кнопка «Назад» есть на каждом экране,
в том числе прямо во дворе.

## Быстрый старт для разработки

Сначала сгенерируй C из скриптов:

```sh
python3 gen.py
```

Файл `game/game.c` создаётся автоматически и в Git не хранится.

### Windows

Нужны Python 3, CMake и компилятор Visual Studio или MinGW:

```sh
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

Готовый файл будет в `build/Release/Game.exe` для Visual Studio или в
`build/Game.exe` для одноконфигурационного генератора.

### Android

Проще всего запустить workflow **Build DS Game** в GitHub Actions. Точные
команды NDK и упаковки APK находятся в `.github/workflows/main.yml`. Сборка
использует API 29 для нативных библиотек и target API 34 для APK.

## Проверки

Головной тест прогоняет настоящий скрипт без окна: лобби, уборку целого дня
настоящими тапами по джойстику, закрытие дня, «Держись», срыв, возврат в лобби,
покупку привычек и восстановление прогресса после перезапуска:

```sh
./test/build_test.sh
./test/game_test
```

Стенд собран с ASAN и UBSAN, поэтому любой ненулевой код выхода означает
поломку. Каждый шаг кладёт скриншот в `test/shots/` (формат PPM) — по ним видно,
что экраны реально нарисовались.

## DimScript в двух словах

DimScript нужен только как компактный слой игровой логики. В нём есть числа,
строки, цвета, массивы, простые объекты и функции. Скрипт компилируется в C,
поэтому в готовой игре нет отдельной виртуальной машины.

```dimscript
object Yarik
num x=0, y=0, bag=0
end

function pick_up Yarik y, num amount
y.bag=clamp(y.bag+amount,0,8)
end
```

Несколько объявлений или коротких команд можно писать в одной строке через `,`
и `;`. Одна тонкость компилятора: тип возвращаемого значения выводится по
последнему `return`, и склейку строк он «видит» только через переменную,
поэтому строки собираются так:

```dimscript
function tr_buy_for num cost
str s="Купить: "+cost
return s
end
```

Основные файлы:

```text
game/config.ds    все константы: скорость, тяга, цены привычек
game/locale.ds    тексты на русском и английском
game/entities.ds  Ярик, мусор, бутылки и состояние забега
game/ui.ds        кнопки, полосы и центрирование текста
game/menu.ds      лобби, привычки, правила, настройки, сохранение
game/game.ds      двор: уборка, тяга, «Держись», срыв
game/engine.ds    переходы между экранами и главные update/draw/touch
ds_compiler.py    компилятор DimScript → C
runtime.c         массивы, строки, клавиатура и базовый рантайм
graphics.c        софтверная отрисовка, PNG и шрифт
net.c             хранилище прогресса (progress.dat) и остатки сетевого слоя
```

Шрифт `game/assets/fonts/ChillRoundGothic_Heavy.ttf` обязателен: из него при
запуске строится атлас для латиницы и кириллицы.
