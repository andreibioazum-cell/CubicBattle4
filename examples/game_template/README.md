# DimScript multi-file game template

Скопируйте эту папку для новой игры. В ней показано, как разделить игру на
несколько файлов `.ds`:

- `game.ds` — точка входа: `init`, `update`, `draw`, `touch`;
- `player.ds` — состояние игрока, отрисовка и joystick;
- `AndroidManifest.xml` — название приложения и Android package;
- `assets/` — ресурсы игры.

Все `.ds`-файлы в одной папке компилируются вместе и видят функции и глобальные
значения друг друга. Порядок файлов задаётся именами файлов, поэтому не
создавайте две функции с одинаковым именем.

Из корня репозитория:

```sh
./gen.sh examples/game_template examples/game_template/game.c
```

Получившийся `game.c` — промежуточный файл, его не нужно редактировать.
