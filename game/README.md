# Game DS

Это папка конкретной игры. Здесь находятся все файлы, которые нужно менять
при создании своей игры:

- `game.ds` — исходный код игры на DimScript;
- `AndroidManifest.xml` — имя приложения, package и настройки Android;
- `assets/` — ресурсы игры (текстуры, звуки и другие файлы).

Чтобы переименовать приложение, измените `android:label`, например на
`Game DS`. Для новой игры также укажите свой уникальный `package` в
`AndroidManifest.xml`.

Из корня репозитория исходник можно скомпилировать так:

```sh
./gen.sh
```

По умолчанию компилятор читает `game/game.ds` и создаёт `game/game.c`.
Сгенерированный `game.c` не нужно редактировать или добавлять в Git.

Для другого исходника можно указать пути явно:

```sh
./gen.sh game/my_game.ds game/my_game.c
```
