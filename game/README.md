# Многофайловая игра Gig1.0 (DimScript)

Структура:
- `game.ds` — главный файл (точка входа)
- `lobby.ds` — меню/лобби
- `game_logic.ds` — логика игры (игрок, цели, таймер)
- `ui.ds` — вспомогательные UI-функции
- `assets/` — PNG-ресурсы

## Сборка
Из корня проекта:
```sh
python3 gen.py game
```

Поддерживаются `#include "file.ds"` (пути относительно текущего файла).

Игра:
- Лобби с кнопкой PLAY
- Виртуальный джойстик (слева внизу): держи и веди пальцем — игрок идёт за
  ручкой джойстика, аналоговая скорость зависит от наклона ручки
- Собирай цели: наезжай на них игроком или быстро тапай по цели
- Таймер 30 секунд, очки за попадания
- Кнопка Back (справа сверху) для возврата в меню
