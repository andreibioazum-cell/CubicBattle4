# Game DS

Это папка конкретной игры. Здесь находятся все файлы, которые нужно менять
при создании своей игры:

- `*.ds` — исходный код игры на DimScript; все такие файлы в папке
  компилируются вместе;
- `AndroidManifest.xml` — имя приложения, package и настройки Android;
- `assets/` — ресурсы игры (текстуры, звуки и другие файлы).

Чтобы переименовать приложение, измените `android:label`, например на
`Game DS`. Для новой игры также укажите свой уникальный `package` в
`AndroidManifest.xml`.

Из корня репозитория исходник можно скомпилировать так:

```sh
./gen.sh
```

По умолчанию компилятор читает все `.ds`-файлы из `game/` и создаёт
`game/game.c`. Функции и глобальные значения доступны между файлами.
Для компактной записи несколько простых команд можно разделять `;` на одной
строке. Сгенерированный `game.c` не нужно редактировать или добавлять в Git.

Для отдельного проекта можно передать папку:

```sh
./gen.sh examples/game_template examples/game_template/game.c
```

Для одного исходника также поддерживается старый формат:

```sh
./gen.sh game/my_game.ds game/my_game.c
```
